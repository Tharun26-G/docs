# 16. Autograd

**Autograd** automatically calculates gradients.


Mathematically:

```text

gradient = 4
```

Output:

```text

```

# 17. Gradient Descent Concept

Suppose:

```text
y = wx + b
```

We want to learn:

```text
w
b
```

Training process:

```text
Input
  ↓
Prediction
  ↓
Loss
  ↓
Gradient
  ↓
Update parameters
  ↓
Repeat
```

Basic example:

```python
x = torch.tensor(2.0)
w = torch.tensor(1.0, requires_grad=True)

y = w * x
loss = (y - 10) ** 2

loss.backward()

print(w.grad)
```

---

# 18. Why `zero_grad()`?

Gradients accumulate by default.

Example:

```python
x = torch.tensor(2.0, requires_grad=True)

y = x ** 2
y.backward()

print(x.grad)

y = x ** 2
y.backward()

print(x.grad)
```

The gradient gets accumulated.

Therefore during training:

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

# 24. Loss Functions

Loss tells the model **how wrong its predictions are**.

---

## Mean Squared Error

Used for regression.

```python
loss_fn = nn.MSELoss()
```

---

## Cross Entropy Loss

Commonly used for multi-class classification.

```python
loss_fn = nn.CrossEntropyLoss()
```


Usually **do not add Softmax before `CrossEntropyLoss`**.

# 26. Complete Training Loop

This is one of the most important PyTorch concepts.

```python
for epoch in range(10):

    model.train()

    for X, y in train_loader:

        X = X.to(device)
        y = y.to(device)

        # Forward pass
        predictions = model(X)

        # Calculate loss
        loss = loss_fn(predictions, y)

        # Clear old gradients
        optimizer.zero_grad()

        # Backpropagation
        loss.backward()

        # Update weights
        optimizer.step()

    print(
        f"Epoch {epoch + 1}, Loss: {loss.item():.4f}"
    )
```

Remember:

```text
model(X)
   ↓
prediction
   ↓
loss_fn()
   ↓
optimizer.zero_grad()
   ↓
loss.backward()
   ↓
optimizer.step()
```

```python
class MyDataset(Dataset):
```

# 35. CNN — Convolutional Neural Network

CNNs are widely used for images.

Typical architecture:

```text
Image
 ↓
Conv2D
 ↓
ReLU
 ↓
Pooling
 ↓
Conv2D
 ↓
ReLU
 ↓
Pooling
 ↓
Flatten
 ↓
Linear
 ↓
Output
```

Example:

```python
class CNN(nn.Module):

    def __init__(self):
        super().__init__()

        self.features = nn.Sequential(
            nn.Conv2d(
                3, 32,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),

            nn.MaxPool2d(2),

            nn.Conv2d(
                32, 64,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),

            nn.MaxPool2d(2)
        )

        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 10)
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x
```

# 47. NLP Model Structure

A simple NLP architecture:

```text
Text
 ↓
Tokenizer
 ↓
Token IDs
 ↓
Embedding
 ↓
Transformer
 ↓
Linear
 ↓
Prediction
```

Example:

```python
class TextClassifier(nn.Module):

    def __init__(
        self,
        vocab_size,
        embed_dim,
        num_classes
    ):
        super().__init__()

        self.embedding = nn.Embedding(
            vocab_size,
            embed_dim
        )

        self.fc = nn.Linear(
            embed_dim,
            num_classes
        )

    def forward(self, x):

        x = self.embedding(x)

        x = x.mean(dim=1)

        return self.fc(x)
```

# 52. Early Stopping

Early stopping prevents unnecessary training.

Concept:

```text
Validation loss improving?
       │
       ├── Yes → Continue
       │
       └── No → Count patience
                    ↓
              Patience reached
                    ↓
                  Stop
```

Simple implementation:

```python
best_loss = float("inf")
patience = 3
counter = 0

for epoch in range(100):

    val_loss = validate()

    if val_loss < best_loss:

        best_loss = val_loss
        counter = 0

        torch.save(
            model.state_dict(),
            "best_model.pth"
        )

    else:

        counter += 1

        if counter >= patience:
            print("Early stopping")
            break
```

# 53. Mixed Precision

Mixed precision can speed up training on supported GPUs.

Modern PyTorch approach:

```python
from torch.amp import autocast, GradScaler

scaler = GradScaler("cuda")

for X, y in train_loader:

    X = X.to(device)
    y = y.to(device)

    optimizer.zero_grad()

    with autocast("cuda"):

        output = model(X)
        loss = loss_fn(output, y)

    scaler.scale(loss).backward()

    scaler.step(optimizer)

    scaler.update()
```

Benefits:

- Faster training
- Lower GPU memory usage
- Useful for large models

An autoencoder learns:

```text

 ↓

 ↓
```

```python
class Autoencoder(nn.Module):

    def __init__(self):
        super().__init__()

        self.encoder = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 32)
        )

        self.decoder = nn.Sequential(
            nn.Linear(32, 128),
            nn.ReLU(),
            nn.Linear(128, 784),
```

# 84. Complete PyTorch Training Template

This is a template worth memorizing:

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

# -----------------------
# Device
# -----------------------

device = torch.device(
    "cuda" if torch.cuda.is_available()
    else "cpu"
)

# -----------------------
# Model
# -----------------------

class Model(nn.Module):

    def __init__(self):
        super().__init__()

        self.network = nn.Sequential(
            nn.Linear(10, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 3)
        )

    def forward(self, x):
        return self.network(x)


model = Model().to(device)

# -----------------------
# Loss
# -----------------------

loss_fn = nn.CrossEntropyLoss()

# -----------------------
# Optimizer
# -----------------------

optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=0.001,
    weight_decay=0.01
)

# -----------------------
# Training
# -----------------------

for epoch in range(10):

    model.train()

    for X, y in train_loader:

        X = X.to(device)
        y = y.to(device)

        # Forward
        output = model(X)

        # Loss
        loss = loss_fn(
            output,
            y
        )

        # Backward
        optimizer.zero_grad()

        loss.backward()

        # Update
        optimizer.step()

    print(
        f"Epoch {epoch + 1}: "
        f"{loss.item():.4f}"
    )

# -----------------------
# Evaluation
# -----------------------

model.eval()

correct = 0
total = 0

with torch.no_grad():

    for X, y in test_loader:

        X = X.to(device)
        y = y.to(device)

        output = model(X)

        prediction = output.argmax(
            dim=1
        )

        correct += (
            prediction == y
        ).sum().item()

        total += y.size(0)

accuracy = correct / total

print("Accuracy:", accuracy)

# -----------------------
# Save
# -----------------------

torch.save(
    model.state_dict(),
    "model.pth"
)
```
