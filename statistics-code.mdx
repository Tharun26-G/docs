# 14. Outlier Detection

```python
import numpy as np

data = np.array([10, 12, 14, 16, 100])

Q1 = np.percentile(data, 25)
Q3 = np.percentile(data, 75)

IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

print(data[(data < lower) | (data > upper)])
```

# 22. Confidence Interval

```python
from scipy import stats
import numpy as np

data = [10,20,30,40,50]

ci = stats.t.interval(
    confidence=0.95,
    df=len(data)-1,
    loc=np.mean(data),
    scale=stats.sem(data)
)

print(ci)
```
